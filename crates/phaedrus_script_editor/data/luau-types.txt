# Luau globals, libraries and Roblox datatypes for script intellisense.
# Classes and enums come from roblox-api.json; this file covers the rest.
#
#   datatype Name      values of this type; `Name` is also a global table of statics
#   library name       a global table of functions/constants
#   .name(...): T      static function (or library function)
#   .name: T           static constant
#   :name(...): T      method on values
#   name: T            property on values
#   global ...         a global function or value
#
# Parameters are `name: Type`, `name: Type?` for optional ones and `...: Type`
# for varargs. A missing return type means nil; `(A, B)` returns several values.
# Anything after `--` is documentation.
